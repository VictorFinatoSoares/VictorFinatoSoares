I use my projects as a way to transform what I study into practical experience.

### 🔎 Finato GitHub Search

One of my projects is **Finato GitHub Search**, a web application I built while learning **React**.

It allows users to search for a GitHub username and retrieve information about that profile using the GitHub API.

Through this project, I practiced concepts such as:

* React components
* State management
* API consumption
* Asynchronous JavaScript
* User input and search
* Conditional rendering
* Component organization
* Deploying a web application
